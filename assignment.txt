
1.API
Server uygulamasına yeni bi REST API yazılacak. POST metodu olacak, dışarıdan request body alacak.Dışarıdan alacağımız body'de application (string),profile (string), prop_key(string), value (string).
JDBC client ile DB'den kayıt okunacak (dışarıdan aldığımız application, profile ve propkey ile bulacağız) ve dışarıdan alınan value güncellenecek.


2. API
Server uygulamasına yeni bir REST API yazılacak. GET metodu olacak. application ve profile alacak. Lokalde (uygulama üzerinde) bir tane map tutacak. key (string), value ()

Dışarıdan aldığımız datalar ile bir tane record ConnectedUsers(String application, String profile, String ipAddress){} oluşturulacak.Oluşturulan record'u Map<String, ConnectedUsers> connectedUsers = new HashMap<>(); bu global map'e eklenecek. Ve bu map döndürülecek.

IP adresi request header'dan bulunacak. key ise application ve profile stringlerinden oluşturulacak.
